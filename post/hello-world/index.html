Hello World: Why I Built This Site

September 01, 2026 · #dev · #personal

I've wanted a small place on the internet that I completely control. Somewhere I can collect my projects, document what I'm learning, and write about the problems I encounter while building software.

That's what this website is for.

Why a personal website?

GitHub is useful for source code. LinkedIn is useful for professional updates. But neither really gives me a place to bring everything together in the way I want.

A personal website gives me one place where I can show the projects I've built, explain the thinking behind them, and write about the things I'm learning without being limited by a particular platform.

It also gives me something I can keep improving over time as my experience, projects, and interests change.

What I'll write about

Most of what I write here will probably come from things I'm actually working on.

That includes full-stack development, React, Node.js, APIs, authentication, databases, deployment, responsive interfaces, data science, and the lessons that come from building real projects.

I don't want this to become a collection of tutorials written only because a topic happens to be popular. I'd rather document problems I've genuinely encountered and explain how I approached them.

Building in public

One of the main projects I'll write about is Nudge, a full-stack productivity application I've built using the MERN stack.

Building it involved much more than creating a React interface. It meant working through authentication, APIs, databases, deployment, responsive design, third-party integrations, and the many smaller problems that appear when turning an idea into a production application.

Those experiences are much more useful when they're documented instead of forgotten after the problem is solved.

A place to keep learning

My background spans both Computer Science and Data Science, so my interests aren't limited to one part of software development.

I'm interested in how software engineering, web development, artificial intelligence, and data-driven systems can come together to build better products.

Some posts will be detailed technical write-ups. Others may simply be short notes about something useful I learned that week.

What comes next

The plan for now is simple:

Build useful things, keep learning, and write down what I learn.

This website will grow alongside that process.
