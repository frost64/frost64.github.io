# Personal Blog Starter

A lightweight personal portfolio + blog built with plain HTML, CSS, and JavaScript.

## Pages

- `/` — Home
- `/about/` — About
- `/projects/` — Projects
- `/blog/` — Blog archive
- `/post/hello-world/` — Example article

## Customize

Search the project for:

- `Your Name`
- `YOURUSERNAME`
- `you@example.com`
- `Your City`

and replace them with your information.

## Run locally

You can simply open `index.html`, or use VS Code Live Server.

## Deploy to GitHub Pages

1. Create a repository named `YOURUSERNAME.github.io`.
2. Upload all files from this folder.
3. Commit and push to the `main` branch.
4. Open GitHub repository **Settings → Pages**.
5. Select **Deploy from a branch**.
6. Choose `main` and `/ (root)`.
7. Your site will be available at `https://YOURUSERNAME.github.io`.

No paid hosting is required.
