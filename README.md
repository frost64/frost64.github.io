## Run Locally

Clone the repository:

```bash
git clone https://github.com/frost64/frost64.github.io.git
```

Move into the project directory:

```bash
cd frost64.github.io
```

No package installation is required because the website uses plain HTML, CSS, and JavaScript.

You can open `index.html` directly in your browser or use the **Live Server** extension in VS Code.

### Using Live Server

Right-click:

```text
index.html
```

and select:

```text
Open with Live Server
```

## Deploy to GitHub Pages

The website is hosted for free using **GitHub Pages**.

Repository:

```text
frost64.github.io
```

GitHub Pages configuration:

```text
Source: Deploy from a branch
Branch: main
Folder: / (root)
```

The website is available at:

🌐 **https://frost64.github.io**

No paid hosting is required.

---

## Updating the Website

After making changes locally:

```bash
git add .
```

Commit the changes:

```bash
git commit -m "Update personal website"
```

Push them to GitHub:

```bash
git push
```

GitHub Pages will publish the updated version from the `main` branch.
